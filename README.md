# treedom

# Manipulação da árvore DOM

Autor: Thiago Ferreira Prates Neves. Programação Web II (2026.2), UESB.

Abra index.html em um navegador. Não exige instalação nem servidor.

## Arquivos

- index.html: enunciados, respostas essenciais e demonstrações.
- estilo.css: tema, componentes, responsividade e impressão.
- exercicios.js: operações, eventos e critérios locais de verificação.
- marca-0.png e marca-1.png: imagens institucionais preservadas.

## Utilização

Todos os exercícios iniciam neutros. Execute os botões dos exercícios 1 e 3, adicione uma tarefa no 2, remova uma notificação no 4 e informe um nome no 5. O verde indica somente que o critério local foi verificado após a operação. Recarregar restaura o estado inicial.

## Decisões

JavaScript nativo, textContent para conteúdo textual, seleção direta das notificações e separação entre HTML, CSS e JavaScript. O título demonstrativo utiliza h2 para manter um único h1 na página integrada; o ID e o comportamento exigidos são preservados. A marca pessoal aparece somente em comentários do fonte e CSS.

## Verificação
