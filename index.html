1. Alterando o Conteúdo de um Elemento

Para praticar a busca e modificação de elementos na tela, considere o cenário em que existe um título principal com texto desatualizado. Dada a estrutura HTML descrita a seguir, escreva o código JavaScript necessário para selecionar o elemento com o identificador "titulo-boas-vindas" e alterar seu conteúdo textual para "Bem-vindo ao Curso de Desenvolvimento de Sistemas!".

<div id="container">
  <h1 id="titulo-boas-vindas">Texto Inicial...</h1>
</div>

Resposta técnica

getElementById seleciona o título. textContent substitui seu conteúdo como texto literal. O botão executa a operação e confere a mensagem resultante.

Código essencial

const titulo = document.getElementById("titulo-boas-vindas");
titulo.textContent = "Bem-vindo ao Curso de Desenvolvimento de Sistemas!";

2. Criando e Adicionando Elementos Dinamicamente

A criação de elementos em tempo de execução é fundamental para interfaces dinâmicas. Considerando uma lista de tarefas vazia ou parcialmente preenchida, crie uma função em JavaScript chamada adicionarItem que receba um parâmetro do tipo texto. Essa função deve criar um novo item de lista e anexá-lo ao final da lista não ordenada que possui o identificador "lista-tarefas".

<h2>Minha Lista de Tarefas</h2>
<ul id="lista-tarefas">
  <li>Estudar sintaxe básica do JS</li>
</ul>

Resposta técnica

createElement cria um li e appendChild o insere ao final. A função recebe o texto e preserva a ordem e as referências dos itens anteriores.

Código essencial

function adicionarItem(texto) {
  const lista = document.getElementById("lista-tarefas");
  const item = document.createElement("li");
  item.textContent = texto;
  lista.appendChild(item);
}

3. Alternando e Alterando Estilos CSS com classList

A alteração visual de componentes no navegador deve ser feita prioritariamente por meio de classes CSS. Com base na estrutura a seguir, escreva um script em JavaScript para selecionar o elemento contêiner com o identificador "painel", remover a classe "oculto" para torná-lo visível e aplicar a classe "destaque" para modificar sua apresentação visual.

<style>
  .destaque { background-color: #fef08a;
          border: 2px solid #eab308;
          padding: 12px; }
  .oculto { display: none; }
</style>

<div id="painel" class="oculto">
  <p>Mensagem importante para o usuário!</p>
</div>

Resposta técnica

classList.remove retira oculto e classList.add aplica destaque. A conferência verifica as classes e os estilos computados nos quatro lados do painel.

Código essencial

const painel = document.getElementById("painel");
painel.classList.remove("oculto");
painel.classList.add("destaque");

4. Remoção de Elementos da Árvore

O gerenciamento da árvore de elementos exige a capacidade de excluir nós desnecessários. Dada a lista de notificações mostrada no código HTML abaixo, desenvolva uma função em JavaScript denominada removerPrimeiraNotificacao. Essa função deve localizar a lista pelo seu identificador "notificacoes" e remover apenas a primeira notificação contida nela sempre que for executada.

<ul id="notificacoes">
  <li id="notif-1">Notificação 1: Atualização de sistema</li>
  <li id="notif-2">Notificação 2: Novo e-mail recebido</li>
  <li id="notif-3">Notificação 3: Lembrete de aula</li>
</ul>

Resposta técnica

querySelector(":scope > li") encontra a primeira notificação diretamente pertencente à lista. remove exclui somente esse elemento; uma verificação impede erro quando a lista está vazia.

Código essencial

function removerPrimeiraNotificacao() {
  const lista = document.getElementById("notificacoes");
  const primeira = lista.querySelector(":scope > li");
  if (primeira) {
    primeira.remove();
  }
}

5. Manipulação com Eventos de Clique

A interatividade em aplicações web é alcançada pela captura de ações do usuário. Utilizando a estrutura HTML abaixo, construa um script em JavaScript que escute o evento de clique do botão com o identificador "btn-exibir". Ao ser acionado, o script deve capturar o texto digitado no campo de entrada com o identificador "campo-nome" e exibir uma mensagem personalizada dentro do parágrafo com o identificador "resposta".

<div>
  <input type="text" id="campo-nome" placeholder="Digite seu nome">
  <button id="btn-exibir">Exibir Mensagem</button>
  <p id="resposta"></p>
</div>

Resposta técnica

addEventListener registra o clique. value recupera o nome e trim elimina espaços nas extremidades. textContent apresenta uma mensagem literal; entrada vazia recebe orientação.

Código essencial

document.getElementById("btn-exibir").addEventListener("click", function () {
  const nome = document.getElementById("campo-nome").value.trim();
  document.getElementById("resposta").textContent = nome
    ? `Olá, ${nome}! Bem-vindo ao estudo de manipulação do DOM!`
    : "Digite seu nome para receber uma mensagem.";
});
